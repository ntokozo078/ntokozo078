My work sits at the intersection of **data engineering and software engineering**  writing clean, testable Python and SQL to design scalable ingestion architectures, Medallion data warehouses, and real-time streaming systems that solve real financial services problems.

## Featured Projects

### SA Financial Crime & Fraud Intelligence Platform
Enterprise-grade financial crime detection platform built on **Microsoft Fabric**.

- Full **Bronze → Silver → Gold Medallion Lakehouse** architecture on Microsoft Fabric
- **PySpark pipelines** joining 900,000+ CIPC company registrations with OpenSanctions KYC data
- **Levenshtein distance fuzzy matching** for accurate sanctions screening
- **Fabric Eventstream + KQL Database** for real-time FICA threshold breach detection
- **Power BI compliance dashboard** connected directly to the Lakehouse SQL Analytics Endpoint
- Stack: `Microsoft Fabric` `PySpark` `KQL` `Delta Lake` `Python` `Power BI`

---

### SA Bank Data Quality & POPIA Pipeline
Production-grade data quality and compliance pipeline for South African banking data.

- **SHA-256 hashing and UUID tokenisation** for POPIA-compliant PII masking
- **8-rule fraud scoring engine** combined with an **IsolationForest ML model** for anomaly detection
- **3-state circuit breaker** for pipeline fault tolerance
- Live **Streamlit monitoring dashboard** with real-time audit logging
- Stack: `Python` `Pandas` `Delta Lake` `Scikit-Learn` `Streamlit` `APScheduler`

---

### SA Job Market ETL Pipeline & Tracker
Self-healing automated pipeline tracking 967+ active job listings daily.

- Ingests from **4 global APIs and web scrapers** across SA, US, UK, and Germany
- Custom **Zombie Filter** to automatically remove expired listings
- **NLP-based skill demand analysis** on job description text
- Deployed on Render with **24-hour cron automation** and PostgreSQL storage
- Stack: `Python` `PostgreSQL` `BeautifulSoup` `NLP` `Flask` `Cron`
